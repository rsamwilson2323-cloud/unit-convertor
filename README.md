# 🔄 Unit Converter

A modern and interactive Unit Converter built using HTML, CSS, and JavaScript. This app allows users to convert temperature, weight, length, and currency with real-time results, theme switching, and local history tracking.

---

## 🚀 Features

- 🌡️ Temperature conversion (Celsius, Fahrenheit, Kelvin)  
- ⚖️ Weight conversion (kg, g, lb, oz)  
- 📏 Length conversion (m, cm, km, mile, ft, inch)  
- 💱 Currency conversion (USD, INR, EUR, GBP)  
- 🎨 Multi-theme UI switcher  
- 📜 History tracking using localStorage  
- ⚡ Fast and responsive design  
- 💻 Fully browser-based (no external libraries)  

---

## 🎯 Usage

1. Enter a value in any category  
2. Select the unit type  
3. Click "Convert"  
4. View instant result  
5. Use "History" to view past conversions  
6. Switch themes using the toggle
